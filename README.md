
# Professional Backend Developer Portfolio

This is a professional single-page portfolio built with React, TypeScript, and Tailwind CSS.

## Getting Started

To run this project locally, follow these steps:

1. **Prerequisites**: Ensure you have [Node.js](https://nodejs.org/) installed.
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Start Development Server**:
   ```bash
   npm run dev
   ```
4. **View the Project**: Open your browser to `http://localhost:5173`.

## Features
- **Responsive Design**: Built with Tailwind CSS v4.
- **Dark Theme**: Professional slate and blue aesthetic.
- **Smooth Navigation**: Section tracking and smooth scrolling.
- **Clean Code**: Modular React components and TypeScript for type safety.
